KCN Core 0.1.6（Android 开发版）
=================================

安装
----
1. 将 KCN-core-0.1.6.apk 传到 Android 手机。
2. 允许文件管理器安装未知应用。
3. 安装并打开「KCN启动器」。
4. 应用使用私有外部目录，不需要申请存储权限。

要求
----
- Android 8.0（API 26）或更高
- 支持 arm64-v8a / x86_64（不同 ABI 使用各自 JRE 资源）
- 网络连接（版本清单、Modrinth、文件下载）

这一版已经实现
--------------
- 独立的 KCN 包名 com.kcn.launcher，自己的界面和原生桥
- Mojang / BMCLAPI 真实版本清单
- 版本元数据、client.jar、运行库、资源索引和资源对象真实下载
- Fabric Loader 元数据、库下载和版本配置
- 已安装实例列表、当前实例切换
- 启动计划生成：classpath、mainClass、Java 路径和 JVM 参数
- JVM 冒烟测试：执行打包的 java -version（实验）
- arm64 / x86_64 双 ABI 运行时资源
- Modrinth Mod / 光影搜索与下载
- 内置 OpenJDK 21 解压到应用私有目录
- 原生下载进度、实时日志、错误日志

这一版还没有完成
----------------
- JVM / LWJGL 启动层：可以测试 JVM，但还没有创建 Minecraft 游戏进程
- Forge / NeoForge 安装器
- Microsoft 登录、触控与渲染配置

这是一个开发里程碑，不是最终可玩版。下载文件位于：
  /sdcard/Android/data/com.kcn.launcher/files/minecraft/
