KCN Core 0.1.8（Android 开发版）
=================================

安装
----
1. 将 KCN-core-0.1.8.apk 传到 Android 手机。
2. 允许文件管理器安装未知应用。
3. 安装并打开「KCN启动器」。
4. 应用使用私有外部目录，不需要申请存储权限。

要求
----
- Android 8.0（API 26）或更高
- 支持 arm64-v8a / x86_64
- 网络连接（版本清单、Modrinth、文件下载）

这一版已经实现
--------------
- 独立的 KCN 包名 com.kcn.launcher，自己的界面和原生桥
- Mojang / BMCLAPI 真实版本清单
- 版本元数据、client.jar、运行库、资源索引和资源对象真实下载
- 下载任务取消与 .part 断点续传
- Fabric Loader 元数据、库下载和版本配置
- 已安装实例列表与当前实例切换
- 启动计划生成：classpath、mainClass、Java 路径和 JVM 参数
- JVM 冒烟测试（java -version）
- 实验性游戏进程启动：调用打包 java + 启动计划
- 双 ABI（arm64-v8a / x86_64）
- Modrinth Mod / 光影搜索与下载
- 内置 OpenJDK 21 解压
- 原生下载进度、实时日志、错误日志

这一版还没有完成
----------------
- LWJGL / OpenGL 启动栈与 Android Surface
- 缺少 LWJGL jar 时，游戏进程会启动后立即报错，日志会显示原因
- Forge / NeoForge 安装器
- Microsoft 登录、触控与渲染配置

这是一个开发里程碑，不是最终可玩版。下载文件位于：
  /sdcard/Android/data/com.kcn.launcher/files/minecraft/
