KCN Core 0.1.10（Android 开发版）
==================================

安装
----
1. 将 KCN-core-0.1.10.apk 传到 Android 手机。
2. 允许文件管理器安装未知应用。
3. 安装并打开「KCN启动器」。
4. 应用使用私有外部目录，不需要申请存储权限。

要求
----
- Android 8.0（API 26）或更高
- 支持 arm64-v8a / x86_64
- 网络连接（版本清单、Modrinth、文件下载）

这一版重点
----------
修复 JVM 冒烟测试中的：
  JVM Permission denied
  Error: trying to exec .../runtime/jre21/bin/java

修复方式：
- 保留 JRE 解压目录
- 将 runtime/jre21/bin/java 符号链接到 APK native 目录中的可执行启动器
- 这样 java 启动器再次 exec 时目标位于可执行的 nativeLibraryDir
- 如果符号链接失败，退回 android.system.Os.symlink

已实现
------
- 独立包名 com.kcn.launcher
- Mojang / BMCLAPI 版本清单
- 版本 JSON / client.jar / libraries / assets 下载
- Fabric Loader 安装
- 实例列表、当前实例切换
- 启动计划、JVM 冒烟测试
- 内置 OpenJDK 21（arm64 / x86_64）
- 内置 LWJGL 3.3.3 jars / natives
- Modrinth Mod / 光影下载
- 下载取消、断点续传、日志

仍未完成
--------
- Android GL Surface / EGL / GLFW 输入桥
- 游戏进程可能仍然在 GLFW/EGL 初始化阶段退出
- Forge / NeoForge、Microsoft 登录、触控

这是开发版，不是最终可玩版。
